Color law

Two committed ramps, one per theme, never mixed. Blue is light-only; turquoise is dark-only. No emoji, one accent per surface. Gradients stay inside the ramp, icon fills, ambient glows, progress fills, never gradient text, never competing hues.

Motion law

Ambient idle loops only: one gentle loop per viewport, everything static by default under reduced motion. Nothing flashes faster than three times per second (WCAG 2.3.1).

Idle

Slow bob on a single sticker, a breathing corner-frame glow on one focal panel.

.sticker--idle · .corner-frame--focal

Reduced motion

Blanket duration collapse plus per-effect static fallbacks: doodles render fully drawn, sweeps freeze, type is never animated in.

@media (prefers-reduced-motion: reduce)

Retired

Gradient text washes, inset/neumorphism shadows, full-page CRT flicker, carousel auto-rotation, and emoji are not part of this system.

law: no gradient text · no emoji

Hand-written HTML/CSS/JS, no frameworks. Analytics only with your consent.
