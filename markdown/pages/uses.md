## The homelab

A self-hosted stack at home runs the way other people run aquariums. It serves models, runs automations, and is why my cloud bill is a rounding error.

- inference: Ollama, local LLMs
- automation: n8n with MCP tool servers
- vectors: Qdrant and Chroma for RAG
- storage: 20TB MinIO, S3 compatible
- platform: Docker, Coolify, Traefik, Tailscale
