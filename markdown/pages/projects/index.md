## Featured project summaries

### Aviz Health

Hero project · Live on Google Play. A digital healthcare ecosystem where patients, doctors, labs, pharmacies, nurses, drivers — and the occasional ambulance — all talk to each other in real time. Three Flutter apps (patient, partner, ground-staff "Heros"), a Next.js 16 admin console, and a Bun + Hono backend over MongoDB with Redis caching, Agora RTC video consultations, Cashfree payments, Google Maps routing, and Firebase Auth. Shipped as v2.0 on Google Play.

### Swalook CRM

Enterprise SaaS · In production. A ground-up architectural overhaul of a salon-management platform serving real merchants with real concurrent workloads. Next.js 16 Turborepo monorepo (five products), Shadcn UI + Recharts dashboards, a Bun + Hono backend on PostgreSQL/Drizzle with Redis and BullMQ, 35+ REST endpoints documented with OpenAPI/Scalar, and a Flutter consumer app with ML Kit face-mesh AR hairstyle previews.

### Genuinest

Founding Engineer · Self-hosted infrastructure. Built the core Flutter product (Riverpod, GoRouter, Hive/SQLite offline-first), a Bun + Hono API with Zod validation and JWT rotation, then spearheaded the migration off high-cost cloud providers to Docker, Coolify, Traefik v3, Tailscale, and a 20TB MinIO storage cluster — with OpenTelemetry/SigNoz observability throughout.

### Vini & Tini

AI/ML research · Published. Two small language models trained from scratch on the BitNet b1.58 ternary architecture: Vini, an edge-first personal assistant wired into a self-hosted Ollama/n8n/MCP/Qdrant ecosystem, and Tini, a TypeScript coding model published on HuggingFace (jayptl-rq/tini, Apache 2.0).

### Tenet PG Management

Full PG/hostel management platform in a Bun + Turborepo monorepo: Next.js 16 dashboard, Hono backend with SSE and UPI payments, PDF invoices — shipped with Playwright and Vitest coverage.

### Ai-Vestor

First place, FinTech track — CHARUSAT-Odoo Hackathon 2025 (650+ applicants, 75 teams). An AI stock-prediction platform with 100+ trained LSTM models and a gamified investment LMS.
